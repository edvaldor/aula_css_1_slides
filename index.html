Hoje na História da Informática

30/04/1993: CERN libera o código do World Wide Web.

O CERN é uma organização de pesquisa nuclear na Suíça. Foi onde Tim Berners-Lee criou a Web como conhecemos.

O Pai da Web

Tim Berners-Lee idealizou e desenvolveu o sistema de hipertexto que deu origem à Web.

História do CSS

Håkon Wium Lie propôs o CSS em 1994 para separar conteúdo e aparência.

Vamos praticar juntos?

<p style="color:blue; font-size:18px">Olá, CSS!</p>

Crie no seu editor de HTML esse exemplo, altere a cor e tamanho da fonte. Observe o efeito.

Exemplo prático com Flexbox

.container {
  display: flex;
  justify-content: space-between;
}

Experimente criar uma div.container com três caixas internas. Altere o alinhamento com justify-content.

Conclusão

O CSS é essencial para criar páginas bonitas e funcionais. Organiza o conteúdo visual e melhora a experiência do usuário.
