O CERN, localizado na Suíça, é o maior laboratório de física de partículas do mundo.

O Pai da Web

Tim Berners-Lee desenvolveu a Web no CERN usando HTML, URI e HTTP.

HTML base

<!DOCTYPE html> <html> <head> <title>Exemplo</title> </head> <body> <h1>Olá Mundo</h1> </body> </html>

CSS em Arquivo Externo

Você pode separar o CSS do HTML criando um arquivo .css e vinculando ao HTML.

Passos:

  1. Crie um arquivo chamado estilo.css
  2. Adicione suas regras CSS nele
  3. No HTML, use: <link rel="stylesheet" href="estilo.css" /> dentro da tag <head>

Exemplo prático com Flexbox

.container {
  display: flex;
  justify-content: center;
}

Adicione 3 divs e alinhe-as horizontalmente.

Conclusão

CSS torna a web mais visual, organizada e responsiva.

Complementos para a Landing Page

Use os seguintes elementos HTML e CSS para montar sua página:

  • <p> para parágrafos descritivos
  • <h1>, <h2> para títulos e subtítulos
  • <img> para imagens (com atributo alt)
  • Use<background-color:#f4f4f4;> para definir cor de fundo
  • Usetext-align, color, font-size nos estilos

Esses recursos básicos permitem construir uma página clara, organizada e visualmente agradável.

Crie uma landing page simples sobre a história do WWW contendo:

  • Texto sobre o CERN
  • Imagem do CERN
  • Bandeira da Suíça
  • Texto sobre Tim Berners-Lee
  • Imagem de Tim Berners-Lee
  • Uso de CSS estudado nesta aula (inline, interno ou externo)

Trabalho simples, porém feito com dedicação e organização!
