Hoje na História da Informática

Em 30 de abril de 1993, o CERN liberou oficialmente o código-fonte do World Wide Web (WWW) para uso público e gratuito.

A criação do WWW é creditada a Tim Berners-Lee, que idealizou um sistema de hipertexto acessível via internet.

Esse marco possibilitou o surgimento dos websites como conhecemos hoje, conectando o mundo por meio da informação digital.

História do CSS

Proposto por Håkon Wium Lie em 1994, o CSS trouxe a separação entre conteúdo e apresentação, tornando o HTML mais limpo e as páginas web mais fáceis de manter.

Regras CSS

p {
  color: red;
  text-align: justify;
  font-size: 20px;
}
h1 {
  color: blue;
  text-align: center;
  font-size: 40px;
}

Ligação do CSS ao HTML

<link rel="stylesheet" href="style.css" />

O atributo rel define a relação como folha de estilo, e href aponta para o arquivo CSS.

Layouts com Flexbox

.container {
  display: flex;
  justify-content: space-between;
}

Conclusão

O CSS é uma ferramenta essencial para construir experiências web modernas, limpas, acessíveis e responsivas.
