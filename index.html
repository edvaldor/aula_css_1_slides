História do CSS

Håkon Wium Lie propôs o CSS em 1994 para separar conteúdo e estilo.

Vamos praticar juntos?

<p style="color:blue; font-size:18px">Olá, CSS!</p>

Modifique cor, fonte e alinhamento. Observe o impacto visual.

Exemplo prático com Flexbox

.container {
  display: flex;
  justify-content: center;
}

Adicione 3 divs e alinhe-as horizontalmente.

Conclusão

CSS torna a web mais visual, organizada e responsiva.
